# TTAM AI Creative Center Demo

Interactive prototype for exploring AI creative strategies and managing their use in campaigns.

- **AI in TikTok Ads:** Visual overlay, Audio refresh, Remix generation and Seedance showcases.
- **Insights:** Three creative examples with CTR and CVR comparisons.
- **Campaigns:** CPA improvements and per-campaign strategy controls.
- **Brand Kit:** Typography, brand copy, logo and colors, with campaign scopes.

Built with HTML, CSS and JavaScript. No build step or dependencies.

## Run locally

Serve this directory with any static web server, for example:

```sh
python3 -m http.server 8765
```

## GitHub Pages

In repository Settings → Pages, select Deploy from a branch, branch `main`, folder `/ (root)`.

This is a browser-local prototype with illustrative data. No live advertising account is connected. Controls persist in local storage.
